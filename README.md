# Password Strength Checker

About This Project:

This is my first project as part of the Decode Labs Cyber Security Internship Program.

The goal of this project was to create a simple password strength checker using Python. The program analyzes a password and classifies it as Weak, Medium, or Strong based on factors such as password length, uppercase letters, numbers, and special characters.

While working on this project, I gained a better understanding of how password policies contribute to security and how basic programming logic can be used to validate user input.

Features

- Checks password length
- Detects uppercase letters
- Detects lowercase letters
- Detects numbers
- Detects special characters
- Classifies password strength as Weak, Medium, or Strong

Technologies Used

- Python 3
- Visual Studio Code

Sample Passwords Tested

- abc → Weak
- hari45 → Medium
- Hari@45 → Strong
